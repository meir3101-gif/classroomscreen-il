# מסך כיתה - Classroomscreen בעברית

אפליקציית מסך כיתה אינטראקטיבית בעברית למורים ותלמידים.

## תכונות עיקריות
- ⏱️ **זמן ויומן:** טיימר, טיימר ויזואלי, סטופר, שעון, מערכת שעות וספירה לאחור.
- 🚦 **ניהול כיתה:** רמזור, סמלי עבודה, מד רעש מבוסס מיקרופון.
- 🎲 **מעורבות והגרלות:** גלגל מזל, הגרלת שמות, קוביות, לוח תוצאות וסקר חי לתלמידים.
- 📝 **מדיה ותוכן:** לוח ציור, תיבות הנחיה, קוד QR, תמונות והטמעות.
- ☁️ **שמירה בענן:** סנכרון מאובטח באמצעות Google OAuth ו-Upstash Redis.

## הרצה מקומית
```bash
npm install
npm start
```
האתר ייפתח בכתובת: `http://localhost:3000`

## בדיקות אבטחה
```bash
npm test
```
